データフロー:
1. Scheduler → 1時間ごとにトリガー
2. Scraper Manager → 全スクレイパーを実行
3. Scrapers → ニュースサイトから記事を収集
4. Database → 記事を保存
5. AI Service → 記事を分析・クラスタリング
6. News Service → イベントとタイムラインを生成
7. Database → イベントデータを保存
8. API → データをフロントエンドに提供
9. Frontend → ユーザーに表示
